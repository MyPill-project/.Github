# Security policy

MyPill handles health data, so we treat security reports as a priority.

## Reporting a vulnerability

Do **not** open a public issue. Email **security@<your-domain>** with:

- what is affected (mobile app, API, firmware, device pairing, infrastructure)
- how to reproduce it
- what an attacker could do with it

We acknowledge reports within 3 working days and keep you informed until it is fixed.

## Leaked secrets

If you commit a secret by mistake, rotate it straight away. Removing it from
git history is not enough, because it may already have been copied.
